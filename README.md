# Альфа-Маршрут — подготовка данных

Часть моей работы аналитиком данных в командном проекте Hack&Change 2026 по кейсу Альфа-Банка. Команда разрабатывала сервис рекомендаций образовательных материалов.

## Моя часть

- Исследовал PostgreSQL-базу из 62 таблиц и связи между материалами, темами и тегами.
- Подготовил датасеты 1 139 материалов: 33 курса, 838 статей, 247 документов, 8 подкастов и 13 вебинаров.
- Написал SQL-запросы для выгрузки данных.
- Очистил HTML и лишние пробелы, преобразовал длительность в минуты, обработал метки опыта.
- Проверил пропуски и дубли идентификаторов, передал данные разработчикам.

В репозитории опубликована часть SQL-запросов и скрипт обработки курсов.

## Файлы

- sql/01_check_courses.sql — заполненность полей и повторяющиеся ID.
- sql/02_export_courses.sql — базовая выгрузка опубликованных курсов.
- sql/03_course_topics.sql — связь курсов с темами.
- clean_courses.py — очистка предварительно собранного датасета курсов.
- requirements.txt — зависимости Python.

## Запуск

Нужны Python 3.11+ и локальный файл data/courses_raw.csv со столбцами course_id, title, description, target, topics, tags, duration, experience_labels, access_type. Отдельные SQL-файлы показывают части подготовки этой выгрузки, а не полный процесс её сборки.

```bash
python -m pip install -r requirements.txt
python clean_courses.py
```

Результат сохраняется в output/courses_clean.csv, отчёт о пропусках — в output/quality_report.csv. Исходные столбцы сохраняются, обработанные добавляются отдельно.

Приблизительное время отмечается отдельным флагом.

SQL выполняется на базе проекта. Без исходной базы и CSV полный процесс запустить нельзя.

Стек: PostgreSQL, SQL, Python, pandas. Для локального запуска базы использовался Docker.
